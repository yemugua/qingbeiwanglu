# 轻备忘录 QingMemo

> **标签**：本地备忘录 · 桌面便签 · 定时提醒 · 悬浮窗 · 免安装 · 不联网 · 隐私保护 · Windows · 单文件 · 绿色软件

完全本地运行的桌面备忘录小工具：逐条记录事项，可设置日期时间和提前提醒。
**不联网、不上传、无需安装任何环境**——数据文件 memos.json 就写在 EXE 所在目录，随时备份。

## 下载

到 [Releases](../../releases) 下载 `轻备忘录-v1.0.0-windows-x64.zip`，解压到任意目录（如桌面），
双击「轻备忘录.exe」即可运行。校验文件：`SHA256SUMS.txt`（zip 整包 sha256：
`3a3587b5d60c42ae7b4a51cf012130417e4123f68999ca2cba2a78fc1915796e`）。

> GitHub Release 附件名为 `qingbeiwanglu-v1.0.0-windows-x64.zip`（GitHub 资产名不支持中文字符，内容与 Gitee 附件完全相同，sha256 一致）。

## 功能亮点

- **桌面悬浮长条**：半透明竖长条常驻屏幕边缘（默认右下角 240×520），默认**鼠标穿透**——看得见但不会挡操作
- **托盘单击唤醒**：长条临时变为可交互，静止 15 秒自动回到穿透状态
- **逐条事项 + 定时提醒**：设日期时间与提前提醒量；程序运行时才提醒，关闭后不提醒
- 数据全部本地存储（memos.json），不上传、无账号

## 使用注意

- 请把 EXE 放在桌面或普通文件夹，**不要**放 `C:\Program Files` 等需管理员权限的位置（否则保存数据失败）
- 建议把 EXE 和 memos.json 放同一文件夹一起备份
- 详细说明见包内「使用说明.txt」
